ÉNONCÉ DU SUJET

Exercice 1 : Activités Numériques (4 points)

On donne l'expression réelle suivante :

$$A = \sqrt{125} - 2\sqrt{20} + 3\sqrt{45}$$

1) Simplifier l'écriture de $A$ sous la forme $a\sqrt{5}$ où $a$ est un entier relatif.

INDICATION / PISTES DE RECHERCHE

Conseils pour l'Exercice 1

Pour résoudre cette question sans bloquer :

  • Pensez à décomposer chaque nombre sous les radicaux en un produit contenant le chiffre $5$.
  • Par exemple : $125 = 25 \times 5$.
  • Utilisez ensuite la formule magique : $\sqrt{x \times y} = \sqrt{x} \times \sqrt{y}$ sachant que $\sqrt{25} = 5$.

CORRIGÉ DÉTAILLÉ

Correction de l'Exercice 1

Décomposons les termes :

$$A = \sqrt{25 \times 5} - 2\sqrt{4 \times 5} + 3\sqrt{9 \times 5}$$ $$A = 5\sqrt{5} - 4\sqrt{5} + 9\sqrt{5}$$ $$A = (5 - 4 + 9)\sqrt{5} = 10\sqrt{5}$$

La réponse finale est $\mathbf{A = 10\sqrt{5}}$.
