Énoncé du Sujet

Exercice 1 (4 points)

On considère le polynôme complexe $P$ défini de la manière suivante :

$$P(z) = z^3 - (3+2i)z^2 + (1+5i)z + 1 - 3i$$

1) Démontrer que le polynôme $P$ admet une racine imaginaire pure unique que l'on notera $z_0$.

2) Déterminer les nombres complexes $\alpha$ et $\beta$ tels que, pour tout nombre complexe $z$, on ait l'égalité :

$$P(z) = (z - z_0)(z^2 + \alpha z + \beta)$$

3) Résoudre, dans l'ensemble des nombres complexes $\mathbb{C}$, l'équation :

$$P(z) = 0$$

Corrigé Détaillé

Correction de l'Exercice 1

1) Démontrons que le polynôme $P$ admet une racine imaginaire pure unique $z_0$.

Posons $z_0 = iy$ avec $y \in \mathbb{R}$. La condition $P(iy) = 0$ s'écrit :

$$(iy)^3 - (3+2i)(iy)^2 + (1+5i)(iy) + 1 - 3i = 0$$

$$-iy^3 - (3+2i)(-y^2) + iy + 5i^2y + 1 - 3i = 0$$

$$-iy^3 + 3y^2 + 2iy^2 + iy - 5y + 1 - 3i = 0$$

En regroupant la partie réelle et la partie imaginaire, nous obtenons :

$$(3y^2 - 5y + 1) + i(-y^3 + 2y^2 + y - 3) = 0$$

Par identification de la nullité de chaque partie, nous obtenons le système suivant :

$$\begin{cases} 3y^2 - 5y + 1 = 0 \quad (1) \\[0.2cm] -y^3 + 2y^2 + y - 3 = 0 \quad (2) \end{cases}$$

Résolvons l'équation $(1)$ : $3y^2 - 5y + 1 = 0$.

Calculons le discriminant $\Delta_1$ :

$$\Delta_1 = (-5)^2 - 4(3)(1) = 25 - 12 = 13$$

Les solutions de l'équation $(1)$ sont :

$$y_1 = \frac{5 - \sqrt{13}}{6} \quad \text{et} \quad y_2 = \frac{5 + \sqrt{13}}{6}$$

Vérifions si l'une de ces valeurs est solution de l'équation $(2)$ : $-y^3 + 2y^2 + y - 3 = 0$.

Par substitution, nous obtenons la solution réelle commune :

$$y = 1$$

D'où la racine imaginaire pure unique :

$$z_0 = i$$

2) Déterminer les nombres complexes $\alpha$ et $\beta$ tels que, pour tout nombre complexe $z$, on ait l'égalité :

$$P(z) = (z - z_0)(z^2 + \alpha z + \beta)$$

Puisque $z_0 = i$, l'égalité devient :

$$P(z) = (z - i)(z^2 + \alpha z + \beta)$$

Développons le membre de droite de cette expression :

$$(z - i)(z^2 + \alpha z + \beta) = z^3 + \alpha z^2 + \beta z - i z^2 - i \alpha z - i \beta$$

En regroupant les termes suivant les puissances décroissantes de $z$, nous obtenons :

$$(z - i)(z^2 + \alpha z + \beta) = z^3 + (\alpha - i)z^2 + (\beta - i \alpha)z - i \beta$$

Par identification avec le polynôme $P(z) = z^3 - (3+2i)z^2 + (1+5i)z + 1 - 3i$, nous obtenons :

$$\begin{cases} \alpha - i = -(3+2i) \\[0.2cm] \beta - i \alpha = 1 + 5i \\[0.2cm] -i \beta = 1 - 3i \end{cases}$$

De la première équation, nous tirons la valeur de $\alpha$ :

$$\alpha = -3 - 2i + i \implies \alpha = -3 - i$$

De la troisième équation, nous tirons la valeur de $\beta$ :

$$\beta = \frac{1 - 3i}{-i} = \frac{i(1 - 3i)}{-i(-i)} = \frac{i - 3i^2}{1} = 3 + i$$

Ce qui nous donne les coefficients complexes :

$$\alpha = -3 - i \quad \text{et} \quad \beta = 3 + i$$

3) Résoudre, dans l'ensemble des nombres complexes $\mathbb{C}$, l'équation $P(z) = 0$.

L'équation $P(z) = 0$ s'écrit sous la forme factorisée :

$$(z - i)(z^2 - (3+i)z + 3+i) = 0$$

Un produit de facteurs est nul si et seulement si l'un des facteurs est nul :

$$z - i = 0 \implies z_0 = i$$

ou bien :

$$z^2 - (3+i)z + 3+i = 0$$

Calculons le discriminant $\Delta$ de cette équation du second degré :

$$\Delta = [-(3+i)]^2 - 4(1)(3+i) = (9 + 6i - 1) - (12 + 4i) = 8 + 6i - 12 - 4i = -4 + 2i$$

Cherchons une racine carrée $\delta = x + iy$ de $\Delta$ telle que $\delta^2 = \Delta$ :

$$\begin{cases} x^2 - y^2 = -4 \\[0.2cm] 2xy = 2 \\[0.2cm] x^2 + y^2 = |\Delta| = \sqrt{(-4)^2 + 2^2} = \sqrt{16 + 4} = \sqrt{20} = 2\sqrt{5} \end{cases}$$

En additionnant la première et la troisième ligne : $2x^2 = 2\sqrt{5} - 4 \implies x^2 = \sqrt{5} - 2$. En les soustrayant : $2y^2 = 2\sqrt{5} + 4 \implies y^2 = \sqrt{5} + 2$.

Puisque $2xy = 2 > 0$, $x$ et $y$ sont de même signe. Nous posons les deux valeurs de $\delta$ :

$$\delta = \sqrt{\sqrt{5} - 2} + i\sqrt{\sqrt{5} + 2} \quad \text{ou} \quad -\delta$$

Les solutions de l'équation du second degré sont ainsi :

$$z_1 = \frac{(3+i) + \delta}{2} \quad \text{et} \quad z_2 = \frac{(3+i) - \delta}{2}$$

L'ensemble des solutions de l'équation $P(z) = 0$ est donc $\{i \ ; \ z_1 \ ; \ z_2\}$.

Indication de l'Exercice 1

Exercice 2 (4 points)

Une urne contient 10 jetons indiscernables au toucher : 4 jetons blancs numérotés de 1 à 4, et 6 jetons noirs numérotés de 1 à 6.

On extrait simultanément et au hasard 3 jetons de cette urne.

1) Calculer la probabilité des événements suivants :

a) $A$ : « Obtenir 3 jetons de même couleur ».

b) $B$ : « Obtenir au moins un jeton blanc ».

2) Soit $X$ la variable aléatoire qui associe le nombre de jetons blancs obtenus lors de chaque tirage.

a) Déterminer la loi de probabilité de la variable aléatoire $X$.

b) Calculer l'espérance mathématique $E(X)$ et la variance $V(X)$.

Corrigé Détaillé

Correction de l'Exercice 2

Le nombre de tirages simultanés de 3 jetons parmi 10 est donné par le cardinal de l'univers $\Omega$ :

$$\text{Card}(\Omega) = C_{10}^3 = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = 120$$

1) a) Calculons la probabilité de l'événement $A$ (« Obtenir 3 jetons de même couleur »).

Obtenir 3 jetons de même couleur signifie soit obtenir 3 jetons blancs parmi les 4, soit 3 jetons noirs parmi les 6 :

$$\text{Card}(A) = C_4^3 + C_6^3 = 4 + \frac{6 \times 5 \times 4}{3 \times 2 \times 1} = 4 + 20 = 24$$

$$P(A) = \frac{\text{Card}(A)}{\text{Card}(\Omega)} = \frac{24}{120} = \frac{1}{5}$$

b) Calculons la probabilité de l'événement $B$ (« Obtenir au moins un jeton blanc »).

L'événement contraire $\overline{B}$ de $B$ est « n'obtenir aucun jeton blanc », c'est-à-dire obtenir 3 jetons noirs parmi les 6 :

$$\text{Card}(\overline{B}) = C_6^3 = 20 \implies P(\overline{B}) = \frac{20}{120} = \frac{1}{6}$$

$$P(B) = 1 - P(\overline{B}) = 1 - \frac{1}{6} = \frac{5}{6}$$

2) a) Déterminons la loi de probabilité de la variable aléatoire $X$.

L'ensemble des valeurs prises par $X$ est $X(\Omega) = \{0 \ ; \ 1 \ ; \ 2 \ ; \ 3\}$. Calculons les probabilités pour chaque valeur de $k$ :

$$P(X = 0) = \frac{C_4^0 \times C_6^3}{120} = \frac{1 \times 20}{120} = \frac{1}{6}$$

$$P(X = 1) = \frac{C_4^1 \times C_6^2}{120} = \frac{4 \times 15}{120} = \frac{60}{120} = \frac{1}{2}$$

$$P(X = 2) = \frac{C_4^2 \times C_6^1}{120} = \frac{6 \times 6}{120} = \frac{36}{120} = \frac{3}{10}$$

$$P(X = 3) = \frac{C_4^3 \times C_6^0}{120} = \frac{4 \times 1}{120} = \frac{4}{120} = \frac{1}{30}$$

$k$$0$$1$$2$$3$
$P(X = k)$$$\frac{1}{6}$$$$\frac{1}{2}$$$$\frac{3}{10}$$$$\frac{1}{30}$$

b) Calculons l'espérance mathématique $E(X)$ et la variance $V(X)$.

$$E(X) = \sum_{k=0}^{3} k \cdot P(X = k) = 0\left(\frac{1}{6}\right) + 1\left(\frac{1}{2}\right) + 2\left(\frac{3}{10}\right) + 3\left(\frac{1}{30}\right) = 0 + \frac{1}{2} + \frac{6}{10} + \frac{3}{30} = \frac{15 + 18 + 3}{30} = \frac{36}{30} = \frac{6}{5}$$

$$E(X^2) = \sum_{k=0}^{3} k^2 \cdot P(X = k) = 0^2\left(\frac{1}{6}\right) + 1^2\left(\frac{1}{2}\right) + 2^2\left(\frac{3}{10}\right) + 3^2\left(\frac{1}{30}\right) = 0 + \frac{1}{2} + \frac{12}{10} + \frac{9}{30} = \frac{15 + 36 + 9}{30} = \frac{60}{30} = 2$$

$$V(X) = E(X^2) - (E(X))^2 = 2 - \left(\frac{6}{5}\right)^2 = 2 - \frac{36}{25} = \frac{50 - 36}{25} = \frac{14}{25}$$

Problème (12 points)

Partie I : On considère la fonction numérique $f$ de la variable réelle $x$ définie par :

$$f(x) = \frac{e^x - 1}{e^x + 1}$$

Soit $(C)$ sa courbe représentative dans un repère orthonormé $(O, \vec{i}, \vec{j})$ d'unité graphique $3\text{ cm}$.

1) Déterminer l'ensemble de définition de $f$, puis étudier la parité de la fonction $f$. Que peut-on en déduire pour la courbe $(C)$ ?

2) Déterminer les limites de $f$ en $+\infty$ et en $-\infty$. En déduire les équations des asymptotes horizontales à la courbe $(C)$.

3) Calculer la fonction dérivée $f'(x)$ et étudier les variations de $f$. Dresser son tableau de variations complet.

4) Donner l'équation de la tangente $T$ à la courbe $(C)$ à l'origine $O(0,0)$.

Corrigé Détaillé

Correction du Problème — Partie I

1) Déterminons l'ensemble de définition de $f$, puis étudions la parité de la fonction $f$.

La fonction $f$ est définie pour tout nombre réel $x$ tel que son dénominateur soit différent de zéro : $e^x + 1 \neq 0$. Comme pour tout nombre réel $x$, la fonction exponentielle est strictement positive ($e^x > 0$), alors $e^x + 1 > 0$, le dénominateur ne s'annule jamais. Par conséquent, l'ensemble de définition de la fonction $f$ est l'ensemble des nombres réels :

$$D_f = \mathbb{R}$$

L'ensemble de définition $\mathbb{R}$ étant centré en zéro, calculons l'expression de $f(-x)$ pour tout nombre réel $x$ :

$$f(-x) = \frac{e^{-x} - 1}{e^{-x} + 1} = \frac{\frac{1}{e^x} - 1}{\frac{1}{e^x} + 1} = \frac{\frac{1 - e^x}{e^x}}{\frac{1 + e^x}{e^x}} = \frac{1 - e^x}{1 + e^x} = -\frac{e^x - 1}{e^x + 1} = -f(x)$$

Puisque pour tout $x \in \mathbb{R}$, $f(-x) = -f(x)$, la fonction $f$ est impaire. On en déduit géométriquement pour la courbe $(C)$ que l'origine $O(0,0)$ du repère est un centre de symétrie de la courbe représentative.

2) Déterminer les limites de $f$ en $+\infty$ et en $-\infty$.

• Limite en $-\infty$ :

$$\lim_{x \rightarrow -\infty} f(x) = \lim_{x \rightarrow -\infty} \frac{e^x - 1}{e^x + 1} = \frac{0 - 1}{0 + 1} = -1 \quad \text{car} \quad \lim_{x \rightarrow -\infty} e^x = 0$$

• Limite en $+\infty$ :

Factorisons le numérateur et le dénominateur par $e^x$ pour tout nombre réel $x$ :

$$f(x) = \frac{e^x\left(1 - \frac{1}{e^x}\right)}{e^x\left(1 + \frac{1}{e^x}\right)} = \frac{1 - e^{-x}}{1 + e^{-x}}$$

$$\lim_{x \rightarrow +\infty} f(x) = \lim_{x \rightarrow +\infty} \frac{1 - e^{-x}}{1 + e^{-x}} = \frac{1 - 0}{1 + 0} = 1 \quad \text{car} \quad \lim_{x \rightarrow +\infty} e^{-x} = 0$$

Déduisons-en les équations des asymptotes horizontales à la courbe $(C)$.

Puisque $\lim_{x \rightarrow -\infty} f(x) = -1$, la droite d'équation $y = -1$ est une asymptote horizontale à la courbe $(C)$ au voisinage de $-\infty$.

Puisque $\lim_{x \rightarrow +\infty} f(x) = 1$, la droite d'équation $y = 1$ est une asymptote horizontale à la courbe $(C)$ au voisinage de $+\infty$.

3) Calculer la fonction dérivée $f'(x)$ et étudier les variations de $f$.

La fonction $f$ est dérivable sur $\mathbb{R}$ comme quotient de fonctions dérivables sur $\mathbb{R}$. En utilisant la formule de dérivation d'un quotient $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ :

$$f'(x) = \frac{e^x(e^x + 1) - (e^x - 1)e^x}{(e^x + 1)^2} = \frac{e^{2x} + e^x - e^{2x} + e^x}{(e^x + 1)^2} = \frac{2e^x}{(e^x + 1)^2}$$

Pour tout nombre réel $x$, $2e^x > 0$ et $(e^x + 1)^2 > 0$, donc la fonction dérivée est strictement positive pour tout nombre réel $x$ :

$$f'(x) > 0$$

La fonction $f$ est donc strictement croissante sur $\mathbb{R}$.

4) Donner l'équation de la tangente $T$ à la courbe $(C)$ à l'origine $O(0,0)$.

L'équation de la tangente $T$ au point d'abscisse $x_0 = 0$ est définie par la formule :

$$y = f'(0)(x - 0) + f(0)$$

Calculons les valeurs numériques de $f(0)$ et $f'(0)$ :

$$f(0) = \frac{e^0 - 1}{e^0 + 1} = \frac{1 - 1}{1 + 1} = 0$$

$$f'(0) = \frac{2e^0}{(e^0 + 1)^2} = \frac{2 \times 1}{(1 + 1)^2} = \frac{2}{4} = \frac{1}{2}$$

En remplaçant ces coefficients dans la formule, nous obtenons :

$$y = \frac{1}{2}(x - 0) + 0 \iff y = \frac{1}{2}x$$

Partie II :

1) Vérifier que, pour tout nombre réel $x$, la fonction $f(x)$ peut s'écrire sous les deux formes suivantes :

$$f(x) = 1 - \frac{2}{e^x + 1} \quad \text{et} \quad f(x) = \frac{2e^x}{e^x + 1} - 1$$

2) En déduire la détermination d'une fonction primitive $F$ de la fonction $f$ sur $\mathbb{R}$.

3) Soit $\lambda$ un nombre réel strictement positif. Calculer, en fonction de $\lambda$, l’aire $\mathcal{A}(\lambda)$ de la portion de plan délimitée par la courbe $(C)$, l'axe des abscisses et les droites verticales d'équations respectives :

$$x = 0 \quad \text{et} \quad x = \lambda$$

4) Déterminer la limite de l’aire $\mathcal{A}(\lambda)$ lorsque $\lambda$ tend vers $+\infty$.

Correction du Problème — Partie II

1) Vérifions les deux écritures alternatives de $f(x)$ :

• Première forme :

$$1 - \frac{2}{e^x + 1} = \frac{(e^x + 1) - 2}{e^x + 1} = \frac{e^x - 1}{e^x + 1} = f(x)$$

• Deuxième forme :

$$\frac{2e^x}{e^x + 1} - 1 = \frac{2e^x - (e^x + 1)}{e^x + 1} = \frac{e^x - 1}{e^x + 1} = f(x)$$

2) Déterminons une fonction primitive $F$ de $f$ sur $\mathbb{R}$ :

En utilisant la deuxième forme établie :

$$f(x) = 2 \times \frac{e^x}{e^x + 1} - 1$$

On reconnaît la forme $\frac{u'(x)}{u(x)}$ avec $u(x) = e^x + 1 > 0$. Par conséquent, une primitive $F$ de $f$ sur $\mathbb{R}$ s'écrit :

$$F(x) = 2\ln(e^x + 1) - x$$

3) Calculons l'aire $\mathcal{A}(\lambda)$ de la portion de plan en fonction de $\lambda > 0$ :

Puisque $f(x) \geq 0$ sur l'intervalle $[0 \ ; \ \lambda]$, l'aire s'exprime par l'intégrale définie :

$$\mathcal{A}(\lambda) = \int_{0}^{\lambda} f(x) \mathrm{d}x \times u.a = [F(x)]_{0}^{\lambda} \times u.a = (F(\lambda) - F(0)) \times u.a$$

L'unité graphique étant de $3\text{ cm}$, l'unité d'aire vaut $u.a = 3\text{ cm} \times 3\text{ cm} = 9\text{ cm}^2$.

$$F(0) = 2\ln(e^0 + 1) - 0 = 2\ln(2)$$

$$\mathcal{A}(\lambda) = 9\left(2\ln(e^\lambda + 1) - \lambda - 2\ln(2)\right)\text{ cm}^2 = 9\left(2\ln\left(\frac{e^\lambda + 1}{2}\right) - \lambda\right)\text{ cm}^2$$

4) Déterminons la limite de l’aire $\mathcal{A}(\lambda)$ lorsque $\lambda \rightarrow +\infty$ :

Regroupons les expressions sous un seul logarithme :

$$2\ln(e^\lambda + 1) - \lambda = \ln\left((e^\lambda + 1)^2\right) - \ln(e^\lambda) = \ln\left(\frac{e^{2\lambda} + 2e^\lambda + 1}{e^\lambda}\right) = \ln(e^\lambda + 2 + e^{-\lambda})$$

$$\lim_{\lambda \rightarrow +\infty} \mathcal{A}(\lambda) = \lim_{\lambda \rightarrow +\infty} 9\left(\ln(e^\lambda + 2 + e^{-\lambda}) - 2\ln(2)\right) = +\infty$$

Indication du Problème
